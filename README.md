# RPG-Funny-Character-Ideas-Generator

A fun little RPG character generator that creates ridiculous fantasy adventurers with random races, classes, traits, and backstories.

### How to Run

1. Make sure these three files are in the same folder:
   - `index.html`
   - `style.css`
   - `script.js`

2. Open `index.html` in your browser  
   (double-click the file or use Live Server in VS Code)

3. Type a name (optional) and click **Summon Character**

---

### Features

- Random funny fantasy characters
- Optional name input
- Clean dark fantasy theme
- Works offline
